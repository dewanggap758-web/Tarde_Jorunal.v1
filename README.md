# 📈 Trading Journal Web Application

Aplikasi web *Trading Journal* yang dikembangkan dari nol untuk mencatat riwayat transaksi, menghitung performa akun secara otomatis, serta melacak metrik *Profit and Loss* (PnL) guna mengevaluasi strategi trading harian maupun mingguan.

---

## 🚀 Key Features

* **Advanced Trade Logging:** Pencatatan lengkap detail transaksi mulai dari instrumen (seperti XAUUSD), tipe posisi (*Long/Short*), harga *entry*, *exit*, hingga catatan psikologi trading.
* **Automated Performance Metrics:** Kalkulasi otomatis untuk mengukur performa akun seperti *Win Rate*, rasio *Risk-to-Reward (RRR)*, dan akumulasi profit/loss.
* **Custom Interactive Dashboard:** Antarmuka bersih bergaya *dark mode* minimalis yang dirancang khusus untuk kenyamanan visual dan analisis data mendalam.
* **Robust Backend Logic:** Pengolahan data berbasis server yang stabil menggunakan framework Django.
